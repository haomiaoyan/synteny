点阵比对是基因组学里最古老的观察方式之一：两条序列分置两轴， 彼此相似处点一个点。共线的地方连成对角线，倒过来的地方是一条反斜线， 搬了家的地方则是脱离主轴的方块。它不解释原因，但把「结构」变成了一眼可见的东西。

这个工具没有超出这个范围。它的价值在于不用装——不需要 conda， 不需要 Java 运行时，不需要把几十兆的 FASTA 交给别人的服务器。 文件留在你的硬盘里，计算在你的 CPU 上完成。

它不算什么

它不做碱基级比对。共线区段之间的间隔一律按断点处理， 所以看到的是结构，不是单碱基的插入与缺失。需要精确变异列表时， 把区段导出去交给 minimap2 或 MUMmer。 这个工具的定位是先看一眼。

一致性由种子密度反推（p ≈ (seeds/span)^(1/k)）， 因为 minimiser 采样偏差而略偏低，只能当估计值看。
